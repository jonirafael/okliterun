# Changelog

## 0.1.0 — 2026-10-26

Preview release.

- Run the active file or the current selection from the editor play button, **OkLiteRun: Run Code** (`Ctrl+Alt+R`, `Cmd+Alt+R` in the editor), and **OkLiteRun: Stop**.
- Python, JavaScript, TypeScript, C, C++, Java, Go, PHP, shell scripts, and PowerShell.
- Integrated terminal by default, with an output-channel mode.
- Shell-aware quoting for bash, zsh, PowerShell 7, Windows PowerShell 5.1, Command Prompt, and WSL.
- Working directory is the file's folder by default, or the workspace root.
- Python runs with the Python extension's selected interpreter when one is available.
- Save before run, selection temp files, and a clear message when a compiler or interpreter is missing.
- Per-language `okliterun.executorMap` overrides.
